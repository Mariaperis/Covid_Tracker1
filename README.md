# 🦠 COVIMAP

Dashboard interactivo de seguimiento COVID-19 desarrollado con React + Vite.

---

## 📌 Sobre el proyecto

COVIMAP es una aplicación web moderna e interactiva que muestra estadísticas globales del COVID-19 mediante diferentes trackers, tablas dinámicas y componentes reutilizables.

El proyecto está inspirado en dashboards profesionales y se centra en:

- Componentes reutilizables
- Diseño responsive
- Interactividad y animaciones
- Renderizado dinámico de datos
- Arquitectura limpia y escalable
- Uso de React Hooks
- Buena experiencia de usuario (UI/UX)

---

## ✨ Funcionalidades

### 🏠 Home
- Landing page moderna
- Fondo dinámico y animado
- Navbar responsive
- Botones interactivos
- Hero section visual

### 📊 Tracker Chats
- Estadísticas globales COVID-19
- Selector dinámico de países
- Cards estadísticas reutilizables
- Efectos hover
- Iconos animados

### 📋 Tracker Tabla
- Tabla dinámica de países
- Paginación
- Búsqueda por palabras clave
- Ordenación por columnas

### 🧱 Vista Tiles
- Visualización de estadísticas en formato grid/cards

### 🌍 CountryWise
- Estadísticas enfocadas por país
- Renderizado dinámico de datos filtrados

### ⚡ Extras
- Floating Action Buttons reutilizables
- Loading animations
- Pantallas "Under Construction"
- Sidebar dinámica
- Navegación entre pantallas

## ⚙️ Instalación

- Clonar el repositorio:
git clone https://github.com/Mariaperis/Covid_Tracker1

- Instalar dependencias:
npm install

- Ejecutar el servidor de desarrollo:
npm run dev
